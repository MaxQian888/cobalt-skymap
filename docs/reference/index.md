## 天文学基础

### 坐标系统

理解天文学坐标系统对于使用 SkyMap 非常重要：

- **地平坐标系**：以观测者为基准，使用方位角和高度角
- **赤道坐标系**：以天赤道为基准，使用赤经和赤纬，是星表的标准坐标系
- **银河坐标系**：以银河平面为基准
- **黄道坐标系**：以黄道为基准，主要用于太阳系天体

SkyMap 支持以上四种坐标系之间的实时转换，并在内部使用统一的 ICRF/CIRS/OBSERVED 管线保证精度。

### 时间系统

天文学使用多种时间系统：

- **世界时 (UT)**：基于地球自转
- **协调世界时 (UTC)**：使用跳秒的原子时间标准
- **UT1**：修正极移后的世界时，用于精密天文计算
- **恒星时**：以地球相对于恒星的自转为基准
- **儒略日**：连续的日计数，便于计算时间间隔
- **TT (地球时)**：用于行星历表计算

SkyMap 内置 EOP（地球定向参数）基线数据，即使离线也能保持高精度的时间与坐标转换。

### 天体运动

- **周日运动**：地球自转导致的东升西落
- **周年运动**：地球公转导致的星空季节变化
- **行星运动**：行星相对于恒星的顺行、逆行与留

### 星等系统

- **视星等**：地球上的观测亮度
- **绝对星等**：标准距离（10 秒差距）处的亮度
- **摄影星等**：特定滤镜的测量亮度

## 观测条件

### 大气影响

地球大气对观测的影响：

- **大气消光**：吸收和散射星光，天顶处最小，地平处约 3 星等
- **大气折射**：改变天体视位置，地平处约 0.5°
- **视宁度**：大气湍流影响图像清晰度
- **光污染**：降低可见极限星等

### 最佳观测条件

- 远离城市光害的暗空
- 晴朗无云或少云
- 低湿度减少大气散射
- 稳定大气（良好视宁度）

## 常用计算

### 角度计算

- 1° = 60′
- 1′ = 60″
- 1° = 3600″

### 距离单位

- **光年**：约 9.46 万亿公里
- **秒差距**：约 3.26 光年
- **天文单位 (AU)**：日地平均距离，约 1.5 亿公里
