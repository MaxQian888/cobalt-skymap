# 常见问题

本文档收集了用户常见的疑问和解答。

## 安装和设置

### Q: 应用无法启动怎么办？

**A**: 尝试以下步骤：

1. 确认系统满足最低要求（Windows 10+/macOS 10.15+/Linux 主流发行版）
2. 重新安装应用
3. 检查防火墙设置
4. 查看错误日志

日志路径：
- Windows: `%APPDATA%\SkyMapTest\logs\`
- macOS: `~/Library/Logs/SkyMapTest/`
- Linux: `~/.local/share/SkyMapTest/logs/`

### Q: 如何卸载应用？

**A**:
- **Windows**: 控制面板 > 程序和功能
- **macOS**: 删除 Applications 文件夹中的应用
- **Linux**: 删除 AppImage 文件，并清理 `~/.config/SkyMapTest`

## 使用问题

### Q: 星图显示不正确？

**A**: 检查以下几点：

1. 确认观测位置设置正确（经纬度或城市选择）
2. 确认时间设置准确
3. 检查显示设置中的星等限制
4. 尝试重置视图设置

### Q: 找不到某个天体？

**A**:
1. 确认天体名称正确（支持梅西耶、NGC、IC 编号及中文名）
2. 尝试使用坐标搜索（如 `12h 30m +45°`）
3. 检查星等限制设置
4. 确认该天体在当前星表数据中

### Q: 时间控制不工作？

**A**:
1. 确认未处于实时模式
2. 检查时间流逝速度设置
3. 尝试暂停后重新启动
4. 按 `T` 键重置到当前时间

### Q: Aladin Lite 引擎无法加载？

**A**:
1. 检查网络连接（Aladin Lite 需要联网加载资源）
2. 尝试切换回 Stellarium 引擎后再次切换
3. 清除浏览器/应用缓存后重试
4. 检查是否有防火墙或代理阻止了 Aladin CDN

### Q: AR 模式黑屏或无法使用？

**A**:
1. 确认设备有摄像头且已授权应用访问
2. 检查浏览器/系统摄像头权限设置
3. 在光线充足的环境下尝试
4. AR 模式目前为实验性功能，部分设备可能不支持

## 性能问题

### Q: 应用运行缓慢？

**A**: 尝试以下优化：

1. 降低星等限制
2. 减少显示的图层（星座图像、坐标网格等）
3. 关闭不需要的辅助线
4. 切换到「性能模式」渲染
5. 更新到最新版本
6. 在设置中降低 Aladin Lite 的瓦片质量

### Q: 内存占用过高？

**A**:
1. 清理缓存数据（设置 > 缓存管理）
2. 减小缓存区域
3. 重启应用
4. 检查是否有内存泄漏（如果持续增长，请提交 Issue）

## 数据和缓存

### Q: 如何下载数据用于离线使用？

**A**:
1. 打开缓存管理器
2. 选择要下载的区域和 survey
3. 点击下载按钮
4. 等待下载完成

离线缓存支持 DSS、SDSS 等多种 survey 的瓦片数据。

### Q: 缓存数据占用空间太大？

**A**:
1. 打开缓存管理器
2. 查看缓存统计
3. 删除不需要的缓存区域
4. 调整缓存大小限制

### Q: 数据更新失败？

**A**:
1. 检查网络连接
2. 确认服务器状态
3. 尝试手动更新
4. 清理缓存后重试

## 设备管理

### Q: 如何添加望远镜？

**A**:
1. 打开设备管理器
2. 点击「添加望远镜」
3. 填写望远镜参数（焦距、口径、类型）
4. 保存配置

SkyMap 内置常见望远镜预设，可直接选择品牌型号自动填充参数。

### Q: 视野计算不准确？

**A**:
1. 检查设备参数是否正确（焦距、传感器尺寸、像素大小）
2. 确认望远镜和相机配置匹配
3. 验证焦距和传感器尺寸单位（mm vs inch）
4. 尝试重新计算

### Q: 如何连接赤道仪？

**A**:
1. 确保赤道仪支持 ALPACA 协议并已启动
2. 在「赤道仪控制」面板输入 ALPACA 设备地址
3. 点击「连接」
4. 连接成功后即可进行 slew 和同步操作

目前支持 ALPACA 协议，ASCOM/INDI 支持正在开发中。

## 观测规划

### Q: 可见性预测不准确？

**A**:
1. 确认位置和时间设置准确
2. 检查地平线遮挡设置（可导入自定义地平线轮廓）
3. 更新大气折射参数
4. 考虑当地天气条件

### Q: 如何导出观测列表？

**A**:
1. 打开目标列表
2. 点击「导出」按钮
3. 选择导出格式（CSV、JSON）
4. 保存文件

### Q: 梅西耶马拉松怎么用？

**A**:
1. 在观测规划中选择「梅西耶马拉松」
2. 设置观测日期（通常在 3 月中旬至 4 月初）
3. 应用会自动生成按最优顺序排列的 110 个梅西耶目标
4. 执行过程中可标记完成状态并自动跳转到下一个目标

## 解板与摄影

### Q: Plate Solving 是什么？怎么用？

**A**: Plate Solving（解板）是将您的天文照片与星表匹配，从而精确确定照片中心坐标和旋转角的过程。

使用方法：
1. 在「解板」功能中上传您的 FITS 或 JPEG 图像
2. 选择在线解板服务
3. 等待匹配完成
4. 查看结果并在星图上定位对应区域

### Q: 曝光计算器给出的参数合理吗？

**A**: 曝光计算器基于以下因素给出建议：
- 目标亮度与表面亮度
- 望远镜焦比与相机量子效率
- 天光质量（Bortle 等级）
- 信噪比目标

建议将计算结果作为起始参考，实际曝光时间还需根据您的具体设备和后期流程调整。

## 安全问题

### Q: 应用数据是否安全？

**A**: SkyMap 采用多层安全防护：

1. **数据存储** — 所有数据以 JSON 格式存储在应用专用目录中
2. **路径沙箱** — 文件操作限制在应用数据目录内
3. **输入验证** — 所有用户输入都经过大小和格式验证
4. **速率限制** — 防止 API 滥用和资源耗尽
5. **密钥保险箱** — API 密钥等敏感凭证通过系统钥匙串加密存储

### Q: 网络请求是否安全？

**A**: 是的，SkyMap 实现了以下保护：

1. **HTTPS 强制** — 所有网络请求默认使用 HTTPS
2. **URL 验证** — 阻止访问私有 IP 和内部网络
3. **SSRF 防护** — 阻止服务端请求伪造攻击

### Q: 如何清除应用数据？

**A**:
1. 打开设置 → 高级
2. 点击「重置应用数据」
3. 确认操作

或手动删除数据目录：
- Windows: `%APPDATA%\SkyMapTest\`
- macOS: `~/Library/Application Support/SkyMapTest/`
- Linux: `~/.local/share/SkyMapTest/`

### Q: 应用会收集用户数据吗？

**A**: 不会。SkyMap 是本地优先应用，所有数据存储在本地，不会向任何服务器发送用户数据。网络请求仅限于获取星图瓦片、天文数据和自动更新检查。

## 其他问题

### Q: 应用支持哪些语言？

**A**: 目前支持简体中文和英文，可通过设置随时切换。更多语言正在计划中。

### Q: 是否有移动版本？

**A**: 目前为桌面端应用（Windows/macOS/Linux），但 UI 已对平板触控做了适配。移动版本在计划中。

### Q: 数据可以导出吗？

**A**: 是的，支持导出观测日志、目标列表、设备配置、星图截图等数据，格式包括 CSV、JSON 和 PNG。

### Q: 如何同步多个设备的数据？

**A**: 目前需要手动导入导出（设置 > 数据管理 > 导入/导出），云同步功能在开发中。

### Q: 自动更新不工作？

**A**:
1. 确认应用是从 GitHub Releases 下载的正式版本（非自行编译）
2. 检查网络连接
3. 手动点击「检查更新」
4. 如果自动更新不可用，应用会提供打开 GitHub Releases 页面手动下载的链接
