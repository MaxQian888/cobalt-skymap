## 基本概念

### 天球

天球是一个假想的无限大球体，观测者位于球心，所有天体都投影在球面上。

### 天极和天赤道

- **天极**：地球自转轴延长线与天球的交点
- **天赤道**：地球赤道平面与天球的交圆

### 黄道

黄道是太阳在天球上的视运动轨迹，与天赤道交角约 23.44°。

### 星等

星等是描述天体亮度的单位：

| 星等 | 可见性 | 示例天体 |
|-----|-------|---------|
| -27 | - | 太阳 |
| -13 | - | 满月 |
| -4 | 最亮 | 金星（最亮时） |
| 0 | 很亮 | 织女星 |
| 2 | 明显 | 北极星 |
| 6 | 肉眼极限 | 暗星 |
| 10 | 双筒 | 需要光学设备 |

### 角度单位

- **度 (°)**：圆周的 1/360
- **角分 (')**：1° = 60'
- **角秒 (")**：1' = 60"

常见参考：
- 满月直径：约 0.5°（30'）
- 木星直径：约 50"（最大时）
- 恒星视直径：< 0.1"

## 坐标参考架

SkyMap 的坐标系统基于现代天球参考架，支持多帧转换：

### ICRF（国际天球参考架）

- 基于 VLBI 观测的惯性参考架
- 对应 J2000.0 历元
- 用于星表和长期天体位置

### CIRS（天体中间参考系）

- 考虑岁差和章动的中间参考架
- 用于高精度实时计算
- 对应当前历元

### OBSERVED（观测坐标）

- 考虑大气折射的最终观测坐标
- 用于实际指向和显示

### 转换管线

SkyMap 使用统一的坐标转换管线（`lib/astronomy/frames.ts` 和 `pipeline.ts`）：

```
ICRF (J2000)
    ↓ 岁差 + 章动
CIRS (当前历元)
    ↓ 地球自转角（ERA / GAST）
TIRS / 观测者本地框架
    ↓ 大气折射模型（Bennett 1982）
OBSERVED (高度/方位)
```

时间尺度参与：
- **UTC** - 协调世界时（用户输入）
- **UT1** - 世界时（用于地球自转角）
- **TT** - 地球时（用于历书计算）

EOP（地球定向参数）基线数据确保离线环境下仍有高精度。

## 时间系统

### 世界时 (UT)

基于地球自转的时间系统，UT1 是主要形式。

### 协调世界时 (UTC)

基于原子时的国际标准时间，与 UT1 保持在 0.9 秒以内。

### 地球时 (TT)

用于天文历表计算的时间尺度，与 UTC 的差值约为 69.184 秒 + 跳秒累积。

### 恒星时

基于恒星背景的时间系统，一个恒星日约 23 小时 56 分 4 秒。

### 儒略日 (JD)

从公元前 4713 年 1 月 1 日中午开始的连续计日系统。

## 天文现象

### 曙暮光

| 类型 | 太阳高度 | 特征 |
|-----|---------|------|
| 民用曙暮光 | 0° ~ -6° | 可进行户外活动 |
| 航海曙暮光 | -6° ~ -12° | 地平线可见 |
| 天文曙暮光 | -12° ~ -18° | 天空接近全黑 |

### 月相

月相周期约 29.5 天（朔望月），主要相位：

- 新月（朔）
- 上弦月
- 满月（望）
- 下弦月

## 赤道仪相关概念

### 时角 (Hour Angle)

天体相对于子午线的角距离，向东为负、向西为正。时角直接决定赤道仪的机械指向：

- 时角 = 0°：天体正好位于子午线上（上中天）
- 时角 > 0°：天体已过中天，向西运动
- 时角 < 0°：天体尚未中天，向东运动

### 子午线翻转 (Meridian Flip)

德国式赤道仪（GEM）在天体过中天前后需要翻转镜筒，以避免望远镜撞到三脚架：

- **翻转前** - 望远镜位于三脚架东侧（通常目视在左侧）
- **翻转后** - 望远镜位于三脚架西侧（通常目视在右侧）
- **最佳翻转时机** - 尽量接近中天时进行，以减少目标重新捕获时间

SkyMap 的 **赤道仪安全模拟器**（`lib/astronomy/mount-safety.ts`）可提前计算最佳翻转窗口并检测潜在的支架碰撞。
