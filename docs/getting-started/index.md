## 系统要求

### Windows

- Windows 10 或更高版本（64 位）
- 至少 4GB 内存
- 500MB 可用磁盘空间

### macOS

- macOS 10.15 (Catalina) 或更高版本
- Intel 或 Apple Silicon 处理器
- 至少 4GB 内存
- 500MB 可用磁盘空间

### Linux

- 主流发行版（Ubuntu 20.04+、Fedora 33+ 等）
- 至少 4GB 内存
- 500MB 可用磁盘空间

## 快速上手

如果您是第一次使用 Cobalt Skymap，建议按照以下顺序阅读：

### 1. 安装应用

根据您的操作系统，参考[安装指南](installation.md)完成应用安装。

### 2. 首次配置

首次启动时，应用会引导您完成基本配置：

- 设置观测位置（可通过 Leaflet 地图选择器或 GPS 定位）
- 选择星图 survey（DSS、SDSS、AKARI 等）
- 配置显示选项与主题偏好
- 可选：配置设备（望远镜、相机、目镜）

### 3. 了解基本概念

阅读[基本概念](basic-concepts.md)了解：

- 天球坐标系（赤道、地平、银道）
- 时间系统（UTC、UT1、TT、地方恒星时）
- 天体坐标表示与参考架转换

### 4. 探索功能

通过[功能导览](quick-tour.md)快速了解主要功能：

- 星图导航与双引擎切换（Stellarium / Aladin Lite）
- 天体搜索与详情查看
- 观测规划与目标推荐
- 设备管理与 FOV 叠加
- 赤道仪控制（如已连接 ALPACA 设备）
