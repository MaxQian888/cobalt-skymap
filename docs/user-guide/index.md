4. 尝试基本操作

### 常见任务

#### 查找一个天体

1. 按 `Ctrl+F` 或点击搜索按钮
2. 输入天体名称（如 "M31"、"木星" 或 "12h 30m +45°"）
3. 从结果列表选择
4. 双击定位到天体

#### 规划今晚的观测

1. 查看「今夜可见」推荐
2. 检查月相与天气
3. 创建观测目标列表
4. 使用高度图计算最佳观测时间
5. 如需拍摄，使用曝光计算器获取建议

#### 配置设备

1. 添加您的望远镜
2. 添加相机与目镜
3. 创建设备配置组合
4. 在星图上测试 FOV 叠加效果

## 键盘快捷键

### 常用快捷键

- `Ctrl+F` — 搜索天体
- `Ctrl+S` — 保存视图书签
- `T` — 跳转到当前时间
- `Space` — 暂停/继续时间
- `+/-` — 放大/缩小
- `方向键` — 旋转视角

更多快捷键请参考[附录 - 键盘快捷键](../appendix/keyboard-shortcuts.md)。
