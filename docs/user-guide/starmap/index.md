# 星图概览

星图是 Cobalt Skymap 的核心功能，提供交互式的实时星空显示。

## 星图界面

### 主显示区

星图主显示区占据窗口的大部分区域：

- **实时渲染**：根据当前时间实时更新星空
- **交互操作**：支持鼠标、键盘和触摸交互
- **平滑动画**：流畅的天体运动效果
- **多层显示**：同时显示多种类型的天体与叠加层

### 状态栏

底部状态栏显示当前信息：

- **时间**：当前模拟时间
- **位置**：观测位置（经纬度）
- **坐标**：鼠标指向位置的坐标（赤道/地平）
- **FOV**：当前视场大小
- **引擎状态**：当前使用的渲染引擎（Stellarium / Aladin Lite）

## 双引擎系统

Cobalt Skymap 支持两种星图渲染引擎，可根据需求自由切换：

### Stellarium Web Engine

- 高精度实时星图渲染
- 恒星、星座、深空天体、太阳系天体的精确位置
- 丰富的文化星图（西方、中国、波利尼西亚等）
- 适合：日常观测、寻星、教学

### Aladin Lite

- 多波段天文巡天数据（DSS、SDSS、AKARI 等）
- FITS 图像叠加
- 分层渐进式高清图像（HiPS）
- 适合：深空摄影规划、科学巡天数据浏览

### 引擎切换

在星图工具栏中点击引擎切换按钮即可在两者之间切换。切换时当前视角坐标会被保留。

## 星图图层

### 恒星层

显示恒星数据：

- **HIPPARCOS**：依巴谷星表，约 11.8 万颗恒星
- **Tycho-2**：第谷星表，约 250 万颗恒星
- **UCAC4**：美国海军天文台星表，超过 1 亿颗恒星

### 深空天体层

显示深空天体：

- **梅西耶天体**：M1-M110
- **NGC 天体**：NGC 星云星团表
- **IC 天体**：IC 索引星表
- **其他深空天体**：Sh2、vdB 等

### 太阳系天体

显示太阳系天体：

- **太阳**：位置和相位
- **月亮**：位置、相位、亮度
- **行星**：八大行星的位置和亮度
- **矮行星**：冥王星、谷神星等

### 人造卫星

显示人造卫星（需要网络连接）：

- **位置**：实时位置
- **轨迹**：运行轨迹
- **可见性**：可见时段

### FOV 叠加层

当您配置了设备后，可以在星图上叠加显示相机或目镜的视场范围：

- 矩形或圆形视场框
- 支持旋转角度预览
- 不同设备配置使用不同颜色区分

## 星图数据来源

### 在线数据

联网时可获取在线数据：

- **HiPS 服务**：高清天文图像
- **DSS**：数字化巡天数据
- **SDSS**：斯隆数字巡天
- **其他服务**：各种专业天文数据

### 离线数据

离线时可使用缓存数据：

- **自动缓存**：浏览过的区域自动缓存
- **手动下载**：下载特定区域数据
- **缓存管理**：管理和清理缓存

## 星图渲染质量

### 渲染模式

多种渲染模式可选：

- **性能模式**：流畅度优先，适合旧设备
- **平衡模式**：性能和质量平衡
- **质量模式**：画质优先，需要较好硬件
- **自定义模式**：手动调整各项参数

### 星等限制

设置显示的最暗星等：

- **城市观测**：4.0-5.0 等
- **郊区观测**：5.5-6.5 等
- **山区/暗空**：7.0 等以上
- **自动调整**：根据缩放级别自动调整

## 辅助显示

### 坐标网格

显示坐标网格帮助定位：

- **地平网格**：方位角和高度角
- **赤道网格**：赤经和赤纬
- **银河网格**：银河坐标系
- **黄道网格**：黄道坐标系

### 星座元素

显示星座相关元素：

- **星座连线**：连接主要恒星形成图案
- **星座边界**：显示星座的官方边界
- **星座名称**：拉丁名和中文译名
- **文化星图**：支持多种文化星座体系

### 参考线和点

重要的参考线和点：

- **天顶**：观测者正上方的点
- **天极**：北天极和南天极
- **黄道**：太阳在天球上的路径
- **银河**：银河系平面
- **赤道**：天赤道
- **本初子午线**：赤经零点

## 天体标签

### 标签内容

可显示的天体标签：

- **恒星名称**：专有名称和拜耳 designation
- **深空天体**：梅西耶、NGC 编号
- **行星名称**
- **天体坐标**：赤经赤纬
- **星等**：天体亮度
- **距离**

### 标签样式

自定义标签样式：

- 字体大小
- 标签颜色
- 半透明背景
- 标签密度控制

## 时间控制

### 时间模式

多种时间模式：

- **实时模式**：显示当前时刻的天空
- **手动模式**：手动设置日期和时间
- **动画模式**：时间自动流逝

### 时间流速

控制时间流逝速度：

- **暂停**：时间停止
- **慢速**：1 秒 = 1 分钟
- **中速**：1 秒 = 1 小时
- **快速**：1 秒 = 1 天
- **超快**：1 秒 = 1 年

### 时间跳转

快速跳转到特定时间：

- **现在**：跳转到当前时间（`T` 键）
- **日落/日出**
- **天文昏影终**：跳转到天文昏影结束
- **自定义**：输入特定时间

## AR 模式

将天球实时叠加到设备摄像头画面上：

- 需要设备支持摄像头
- 在光线充足的环境下效果最佳
- 辅助现场寻星和天体识别
- 可通过工具栏按钮开启/关闭
