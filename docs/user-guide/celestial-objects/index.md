# 天体对象

Cobalt Skymap 提供丰富的天体信息查询和显示功能，支持从星图点选、搜索定位到深度信息浏览的完整工作流。

## 支持的天体类型

### 恒星

- **亮星** - Hipparcos 星表中的恒星
- **双星** - 物理双星和光学双星
- **变星** - 各类变星（造父变星、食双星等）

### 深空天体 (DSO)

- **星系** - 椭圆星系、旋涡星系、不规则星系
- **星云** - 发射星云、反射星云、暗星云、行星状星云
- **星团** - 疏散星团、球状星团

### 太阳系天体

- **行星** - 八大行星
- **卫星** - 主要卫星
- **小行星** - 已编号小行星
- **彗星** - 周期彗星和新发现彗星

### 人造天体

- **卫星** - ISS、星链等人造卫星
- **空间站** - 国际空间站、天宫等

## 天体搜索

### 快速搜索

1. 点击搜索框或按 `Ctrl+F`
2. 输入天体名称或编号
3. 从结果列表中选择

### 支持的搜索格式

Cobalt Skymap 内置智能天体名称解析器，支持多种输入格式：

| 格式 | 示例 | 说明 |
|------|------|------|
| 通用名称 | 猎户座大星云、仙女座星系 | 中文/英文通用名 |
| Messier 编号 | M31、M42、M1 | 梅西耶天体表 |
| NGC 编号 | NGC 7000、NGC 6992 | 星云星团新总表 |
| IC 编号 | IC 434、IC 1396 | 索引星表 |
| HD 编号 | HD 48915（天狼星） | 亨利·德雷伯星表 |
| HIP 编号 | HIP 32349 | 依巴谷星表 |
| 拜耳命名 | α Ori、β And | 希腊字母 + 星座缩写 |
| 坐标输入 | 05h 35m 17s -05° 23' 28" | 赤经赤纬直接定位 |

### 高级搜索

打开高级搜索对话框（`Ctrl+Shift+F`）：

- **类型筛选** - 按天体类型过滤
- **星等范围** - 设置亮度限制
- **大小范围** - 设置角直径限制
- **高度限制** - 仅显示当前可见目标

## 天体信息面板

### 打开方式

- 点击星图上的天体
- 在搜索结果中点击
- 从目标列表中选择

### 信息内容

#### 基本信息

- **名称** - 通用名称和目录编号
- **类型** - 天体分类
- **坐标** - 赤经、赤纬（支持 ICRS / CIRS / 观测坐标多帧显示）
- **星等** - 视星等、绝对星等

#### 物理参数

- **大小** - 角直径或实际尺寸
- **距离** - 到地球的距离
- **光谱类型** - 恒星光谱分类
- **红移** - 星系红移值

#### 观测信息

- **当前高度** - 实时高度角
- **方位角** - 当前方位
- **升落时间** - 今日升起和落下时间
- **中天时间** - 过中天时刻
- **时角** - 当前时角（用于赤道仪跟踪参考）

#### 升落中天网格

信息面板中可展开 **升落中天网格**，一览今日关键时间节点：

| 事件 | 时间 | 高度 |
|------|------|------|
| 升起 | --:-- | --° |
| 上中天 | --:-- | --° |
| 落下 | --:-- | --° |

> 对于拱极星，升起/落下可能显示为"不可见"或"始终可见"。

### 扩展信息

点击 "更多信息" 获取：

- **SIMBAD 数据** - 专业天文数据库信息
- **维基百科** - 科普介绍
- **图片** - 专业拍摄图像
- **参考文献** - 相关研究论文

## 天体图库

### 查看图像

天体信息面板中点击图像标签：

- **DSS 图像** - 数字化巡天图像
- **专业照片** - 望远镜拍摄图像
- **用户照片** - 社区分享图像

### 图像操作

- **缩放** - 滚轮或双指缩放
- **平移** - 拖动移动
- **旋转** - 调整方向
- **反转** - 切换反色显示

## Aladin Lite 双引擎对比

在 Aladin Lite 视图中浏览同一天体，可以：

- 切换多波段巡天图像（DSS、2MASS、AllWISE、GALEX 等）
- 叠加 SIMBAD 天体目录源
- 对比不同波段的形态差异

> Aladin Lite 与 Stellarium Web Engine 共享同一套天体选择状态，切换引擎时当前目标保持不变。

## 天体名称翻译

### 多语言支持

天体名称支持多种语言显示：

- **中文** - 中国传统星名
- **英文** - 国际通用名称
- **拉丁文** - 科学命名
- **本地语言** - 当地传统名称

### 切换语言

1. 打开设置
2. 选择 "显示"
3. 设置 "天体名称语言"

## 收藏和标记

### 添加收藏

在天体信息面板中点击收藏图标：

- 收藏的天体会保存到本地
- 可以在收藏列表中快速访问
- 支持分组管理

### 添加到目标列表

点击 "添加到目标" 按钮：

- 快速添加到当前观测列表
- 设置优先级和备注
- 规划观测顺序

### 快捷操作

信息面板支持一键操作：

- **Slew 到目标** - 如已连接赤道仪，自动指向该天体
- **添加到目标列表** - 加入当晚观测计划
- **添加标记** - 在星图上标记该位置
- **查看高度曲线** - 打开该天体的高度变化图表
