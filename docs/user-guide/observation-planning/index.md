# 观测规划

SkyMap 提供强大的观测规划功能，帮助您充分利用每一个晴朗的夜晚。

## 功能概览

### 智能推荐

- **今夜推荐** — 根据当前条件推荐最佳观测目标，支持摄影/目视/混合三种评分模式
- **最佳时间** — 计算每个目标的最佳观测时段
- **月相考虑** — 自动避开月光干扰

### 目标管理

- **目标列表** — 创建和管理观测目标清单
- **优先级排序** — 根据可见性和条件自动排序
- **状态追踪** — 记录观测进度（未观测/已完成/已跳过/失败）

### 时间规划

- **高度图表** — 显示目标高度随时间变化
- **曙暮光时间** — 精确计算天文昏影时间
- **会话规划** — 优化多目标观测顺序

## 核心组件

### 今晚推荐面板

系统自动分析当前条件，推荐最适合观测的目标：

- 根据位置计算目标可见性
- 考虑月相和天气条件
- 按推荐分数排序显示
- 一键添加到目标列表
- 支持三种评分模式：
  - **成像模式**：优先考虑拍摄条件（目标高度、背景天空亮度）
  - **目视模式**：优先考虑肉眼/望远镜观测条件
  - **混合模式**：综合考虑两种场景

### 天空图集面板

浏览和搜索深空天体目录：

- Messier、NGC、IC 目录
- 高级筛选（类型、亮度、大小、星座）
- 模糊搜索支持
- 详细天体信息

### 高度图表

可视化目标在夜间的高度变化：

- 实时高度曲线
- 子午线标记（最高点）
- 薄暮时段显示
- 多目标对比
- 最佳观测窗口高亮

### 曝光计算器

天文摄影曝光参数计算：

- 信噪比估算
- 最佳曝光时间建议
- 叠加帧数建议
- 设备参数配置
- 天光质量（Bortle 等级）影响

### 梅西耶马拉松

专为 Messier Marathon 设计的完整工作流：

- 自动生成按最优顺序排列的 110 个梅西耶目标
- 考虑观测者纬度和日期优化排序
- 执行过程中可标记完成状态
- 自动跳转到下一个目标

## 使用流程

### 1. 查看今晚条件

打开应用后，首先查看：

- 日落/日出时间
- 天文昏影时段
- 当前月相
- 天气预报（如果可用）

### 2. 选择观测目标

通过以下方式选择目标：

- 查看系统「今夜推荐」
- 在天空图集中搜索
- 从历史记录中选择
- 手动输入坐标

### 3. 规划观测顺序

使用规划工具优化顺序：

- 按高度优先（避免低角度观测）
- 按子午线时间
- 避免频繁换向
- 考虑设备限制

### 4. 执行观测

观测过程中：

- 实时查看目标状态（高度、方位）
- 记录观测笔记
- 标记完成状态
- 添加新发现

### 5. 跟踪执行与回流调整

新版执行工作流将计划器与观测日志串联：

- **计划器执行概览** — 显示当前执行状态、已完成/已跳过/失败/剩余统计，以及当前或下一个目标
- **剩余目标重排** — 当条件变化时，仅对仍可执行的目标重排，已完成、已跳过、失败或手动锁定的目标会被保留
- **观测日志执行工作区** — 支持对目标执行「开始 / 完成 / 跳过 / 失败」操作，并同步执行摘要
- **快速回到计划器** — 在观测日志中可直接打开关联计划器，继续复盘或调整后续安排

如果某次执行已经全部完成，计划器会显示完成态摘要，并提供归档入口，方便清理当前流程。

## 观测日志

结构化记录每次观测 session：

- 记录观测目标列表
- 记录使用的设备配置
- 记录环境条件（天气、温度、视宁度）
- 添加文字笔记和评分
- 关联到计划器执行摘要
- 支持导出为多种格式
