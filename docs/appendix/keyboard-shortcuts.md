# 键盘快捷键

本文档列出 SkyMap 中可用的键盘快捷键。

## 全局快捷键

### 文件与操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+S` | 保存当前视图书签 |
| `Ctrl+F` | 搜索天体 |
| `Ctrl+,` | 打开设置 |
| `Ctrl+Q` | 退出应用 |

## 星图控制

### 视角控制

| 快捷键 | 功能 |
|--------|------|
| `↑` | 向上旋转视角 |
| `↓` | 向下旋转视角 |
| `←` | 向左旋转视角 |
| `→` | 向右旋转视角 |
| `Home` | 跳转到天顶 |
| `End` | 跳转到天底 |

### 缩放控制

| 快捷键 | 功能 |
|--------|------|
| `+` 或 `=` | 放大 |
| `-` 或 `_` | 缩小 |
| `0` | 重置缩放 |

### 时间控制

| 快捷键 | 功能 |
|--------|------|
| `T` | 跳转到当前时间 |
| `Space` | 暂停/继续时间流逝 |
| `,` | 减慢时间流速 |
| `.` | 加快时间流速 |
| `/` | 恢复正常时间流速 |

## 视图与界面

| 快捷键 | 功能 |
|--------|------|
| `F11` | 全屏模式 |
| `N` | 切换夜视模式 |
| `F1` | 显示/隐藏侧边栏 |
| `F2` | 显示/隐藏信息面板 |

## 图层控制

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+1` | 切换恒星层 |
| `Ctrl+2` | 切换深空天体层 |
| `Ctrl+3` | 切换太阳系天体层 |
| `Ctrl+4` | 切换星座连线 |
| `Ctrl+5` | 切换坐标网格 |
| `Ctrl+6` | 切换地平线 |
| `Ctrl+7` | 切换黄道线 |

## 搜索

### 在搜索框中

| 快捷键 | 功能 |
|--------|------|
| `Esc` | 关闭搜索 |
| `Enter` | 确认搜索 |
| `↓` | 下一个结果 |
| `↑` | 上一个结果 |

## 观测规划

| 快捷键 | 功能 |
|--------|------|
| `Ctrl+R` | 打开今夜推荐 |
| `Ctrl+A` | 打开天空图集 |
| `Ctrl+Enter` | 添加到目标列表 |
| `Alt+H` | 查看高度图表 |

## 标记和书签

| 快捷键 | 功能 |
|--------|------|
| `M` | 在鼠标位置添加天空标记 |
| `Ctrl+M` | 管理标记 |
| `Ctrl+B` | 管理书签 |

## 触摸手势（触屏设备）

- 单指拖动：旋转视角
- 双指捏合：缩放
- 双指拖动：平移
- 三指上滑：显示侧边栏
- 三指下滑：隐藏侧边栏

## 自定义快捷键

部分快捷键可在设置中自定义：

1. 打开设置（`Ctrl+,`）
2. 选择「键盘」选项卡
3. 点击要修改的快捷键
4. 按下新的组合键
5. 保存设置
